# RafChat — чат и передача файлов по локальной сети организации

Автор: Рафаил Шарапов · связь: rafail@sharapov-cnc.ru

Программа для ПК (Windows 10/11), приложения для Android и iPhone. Работает **без сервера и без интернета**:
нужна только локальная сеть (кабель или Wi-Fi). Рассчитана на небольшую организацию (~10 человек).

- **Общий чат** для всех и **личные чаты** с каждым коллегой.
- **Файлы** любого размера: перетащите в окно или нажмите скрепку 📎. Файлы до 50 МБ скачиваются
  у получателя сами, бо́льшие — кнопкой «Скачать». При обрыве связи докачиваются с места остановки.
  Полученные файлы лежат в `Загрузки\RafChat`.
- Зелёная точка у имени — коллега в сети.
- ✓✓ — сообщение доставлено.
- 🕓 — получатель выключен: сообщение ждёт на ПК отправителя и уходит, как только получатель появится в сети.
- «✓ 3/7» в общем чате — скольким участникам сообщение уже доставлено.
- Уведомления о новых сообщениях. Программа работает в фоне (значок у часов) и запускается вместе с Windows.

## Установка
Файлы лежат в **Releases → «rafchat-latest»**:
- `RafChat-Setup-<версия>.exe` — на каждый ПК. Нужны права администратора: установщик сам добавляет
  RafChat в исключения брандмауэра Windows, иначе коллеги не смогут присылать сообщения на этот ПК.
- `RafChat-<версия>.apk` — на телефоны Android. После установки разрешите уведомления. На Xiaomi в «Профиле»
  включите «Работа в фоне без ограничений» и «Автозапуск».

### iPhone
`RafChat-<версия>-iOS-unsigned.ipa` — для iPhone (iOS 16 и новее). Ставится без Mac, программой
**Sideloadly** на Windows: подключите iPhone кабелем, перетащите `.ipa` в Sideloadly, войдите своим Apple ID.
Затем на iPhone: Настройки → Основные → VPN и управление устройством → доверять своему Apple ID.
С бесплатным Apple ID подпись действует **7 дней** — потом снова «Start» в Sideloadly (переписка сохраняется).

Особенности iPhone:
- сообщения приходят, **пока RafChat открыт** (iOS усыпляет свёрнутые приложения, а сервера у нас нет);
  недоставленное ждёт у коллег и приходит сразу после открытия — ничего не теряется;
- при первом запуске iPhone спросит разрешение «Локальная сеть» — нажмите «Разрешить»;
- коллег iPhone находит сам, обходя адреса своей Wi-Fi сети (широковещание Apple без особого разрешения
  запрещает); полученные файлы — в «Файлы → На iPhone → RafChat».

**Подпись своим аккаунтом разработчика Apple (TestFlight, App Store).** Сборка подпишет приложение сама,
если в репозитории (Settings → Secrets and variables → Actions) есть секреты:
`IOS_CERT_P12_BASE64` и `IOS_CERT_PASSWORD` (сертификат Apple Distribution в .p12, base64),
`IOS_PROFILE_BASE64` (профиль для `ru.sharapov.rafchat`, base64), `IOS_TEAM_ID`,
по желанию `IOS_EXPORT_METHOD` (`app-store` по умолчанию или `ad-hoc`). Для автоматической отправки
в TestFlight добавьте ключ App Store Connect: `ASC_API_KEY_P8_BASE64`, `ASC_API_KEY_ID`, `ASC_ISSUER_ID`.

При первом запуске каждый вводит **имя**, **отдел** (по желанию) и **код организации**.
**Код организации должен быть одинаковым у всех**: придумайте его (например `Цех-2026`) и сообщите коллегам.
Устройства с другим кодом вашу переписку не видят и писать в неё не могут.

## Работа через интернет (из дома, в дороге) — свой сервер
В офисе всё идёт напрямую по локальной сети. Чтобы писать и получать сообщения, когда вы не в офисе,
поставьте на свой VPS (Ubuntu/Debian, можно рядом с VPN — порт отдельный) ретранслятор RafChat:

```
curl -fsSL https://raw.githubusercontent.com/sharapovrafail-bot/modelview/claude/adoring-edison-95p0fr/rafchat/server/install.sh | sudo bash
```

В конце установщик покажет адрес вида `203.0.113.5:47888`. Впишите его на **каждом** устройстве:
ПК — ⚙ → «Профиль и сеть» → «Сервер для работы через интернет»; телефон — «Профиль» → то же поле.
Если устройства не подключаются, откройте TCP-порт 47888 в панели хостинга.

- Кого нет в вашей сети, тот «в сети через интернет»; сообщения к нему идут через сервер:
  «✓ на сервере» — сервер принял, «✓✓» — получатель забрал.
- Выключенному получателю сервер хранит сообщения и файлы до 7 дней.
- Файлы через сервер — до 50 МБ.
- **Сервер не может прочитать переписку**: всё шифруется на устройствах (AES-256-GCM) ключом из кода
  организации, а сам код на сервер не передаётся.
- Обслуживание: `systemctl status rafchat-relay`, журнал — `journalctl -u rafchat-relay`,
  обновление — та же команда установки.

## Если коллеги не появляются в списке
1. Проверьте, что все в одной сети (один роутер, один офис), а телефоны подключены к Wi-Fi этой же сети.
2. Проверьте, что на ПК RafChat поставлен установщиком: именно он создаёт правило брандмауэра «RafChat».
3. Если сеть разбита на сегменты (VLAN) и маяки до других ПК не доходят: ⚙ → «Профиль и сеть» →
   «Адреса других ПК» — впишите IP-адреса коллег через запятую.

Если маяки где-то теряются (энергосбережение Wi-Fi на телефоне, VPN на ПК), RafChat всё равно найдёт
собеседника: участник считается «в сети», как только от него пришло сообщение, а известные адреса
раз в несколько секунд опрашиваются напрямую по TCP («ты тут?»). Сообщения «Общего чата», отправленные,
когда кого-то ещё не было видно, досылаются ему, как только он появится (за последние сутки).

## Как устроено
| | |
|---|---|
| Поиск | каждые 4 с маяк «я здесь» (UDP 47800): широковещательно и на известные адреса; запасной путь — `GET /ping` по TCP |
| Сообщения и файлы | HTTP на TCP 47801: `POST /msg`, `GET /file?fid=` (с докачкой через Range) |
| Защита | все маяки и запросы подписаны HMAC-SHA256 ключом из кода организации; через сервер — ещё и шифрование AES-256-GCM |
| Сервер (необязательно) | `server/rafchat_relay.py` — «почтовый ящик» для зашифрованных сообщений, HTTP 47888 |
| Хранение | переписка — в SQLite на каждом устройстве; очередь недоставленного — у отправителя |

Файл из общего чата каждый получатель скачивает напрямую у отправителя. Поэтому, пока файл не скачан,
отправитель должен хотя бы раз появиться в сети. Текст сообщений не шифруется, только подписывается —
для локальной сети организации этого обычно достаточно.

## Разработка
- ПК: `pip install -r pc/requirements.txt`, затем `python pc/rafchat_pc.py`.
  Чтобы запустить две копии на одном ПК, задайте каждой свои переменные `RAFCHAT_HOME`, `RAFCHAT_PORT`
  и `RAFCHAT_UDP`, а в «Адресах других ПК» укажите адрес второй копии (например `127.0.0.1:47900`).
- iPhone: проект в `ios/` (SwiftUI). На Mac: `brew install xcodegen`, `xcodegen generate` в папке `ios/`,
  затем открыть `RafChat.xcodeproj` в Xcode.
- Android: проект в `android/` — открыть в Android Studio или собрать `gradle assembleRelease`.
  APK подписывается тем же постоянным ключом, что и RafLink (`raflink/android/app/raflink.keystore`).
