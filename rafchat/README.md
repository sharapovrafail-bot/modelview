# RafChat — чат и передача файлов по локальной сети организации

Автор: Рафаил Шарапов · связь: rafail@sharapov-cnc.ru

Программа для ПК (Windows 10/11), приложения для Android и iPhone. Работает **без сервера и без интернета**:
нужна только локальная сеть (кабель или Wi-Fi). Рассчитана на небольшую организацию (~10 человек).

- **Общий чат** для всех и **личные чаты** с каждым коллегой.
- **Файлы** любого размера: перетащите в окно или нажмите скрепку 📎. Файлы до 50 МБ скачиваются
  у получателя сами, бо́льшие — кнопкой «Скачать». При обрыве связи докачиваются с места остановки.
  Полученные файлы лежат в `Загрузки\RafChat`.
- Зелёная точка у имени — коллега в сети.
- ✓✓ — сообщение доставлено.
- 🕓 — получатель выключен: сообщение ждёт на ПК отправителя и уходит, как только получатель появится в сети.
- «✓ 3/7» в общем чате — скольким участникам сообщение уже доставлено.
- Уведомления о новых сообщениях. Программа работает в фоне (значок у часов) и запускается вместе с Windows.
- **Фото профиля**: на ПК ⚙ → «Фото профиля…», на телефоне ⚙ → нажмите на кружок. Коллеги увидят его сами.
- **Камера** (телефон): кнопка 📷 рядом с полем ввода — снимок сразу уходит в чат (сжимается, как в WhatsApp).
- **Смайлики**: кнопка 🙂 (разделы: лица, жесты, «цех» — инструмент и станки, разное).
  Сообщение только из 1–3 смайликов показывается крупно.
- **Удалить чат**: на ПК — правой кнопкой по чату, на телефоне — долгим нажатием. Удаляется только у вас;
  «Общий чат» можно очистить. Если удалённый коллега снова появится в сети, чат вернётся.
- Фон переписки — узор из чертёжных мотивов (шестерни, гайки, штангенциркуль, размеры).
- **Фото прямо в переписке** (как в WhatsApp); нажатие — открыть крупно.
- **Один человек — один чат, как в WhatsApp.** Если у сотрудника RafChat стоит и на ПК, и на телефоне (Mac, iPhone)
  с **одинаковыми именем и отделом/должностью**, коллеги видят один чат с ним; сообщение приходит на все его
  устройства, а его ответы с любого устройства видны везде (его собственные устройства получают копию переписки).
- **Список чатов — как в WhatsApp**: сверху «Общий чат», ниже только те, с кем есть переписка (кто написал
  вам или кому написали вы), свежие выше. Начать разговор — кнопка ✏️ «Новый чат» (выбрать сотрудника).
- **Внешние контакты** (заказчики, поставщики — люди не из организации): у каждого есть «Мой код для
  внешних контактов» (12 букв и цифр, на ПК — ⚙ → «Мой код…», на телефоне — под вашим именем). Передайте
  код человеку — он добавит вас через ✏️ «Новый чат → Добавить внешний контакт по коду», и вы
  переписываетесь и пересылаете файлы (до 50 МБ). Идёт через сервер, зашифровано; код один на все ваши
  устройства; ваш общий чат и сотрудников внешний человек не видит. Внешний контакт помечен 🌐.
- **Переустановили программу или сменили телефон** — старая запись с тем же именем и отделом сама
  склеивается с новой: переписка переезжает, «двойника» нет.
- **Карточки заданий для цеха** (кнопка 📋 рядом с полем ввода): деталь, чертёж/УП, материал, количество,
  срок, исполнитель, примечание. Статус меняют кнопками прямо на карточке: «Новое → В работе → Готово →
  Принято ОТК» (или «Доработка»); смена статуса видна у всех и приходит уведомлением. Просроченный срок
  подсвечивается. Все задания — кнопка 📋 рядом с поиском (сначала «Доработка» и «В работе»).
  Файлы к заданию (модель, УП, чертёж, фото): кнопка «📎 Прикрепить» в окне задания (на телефоне ещё и
  «📷 Фото чертежа») или «📎 Файл» на самой карточке — они встают под карточку ответом на неё.
- **Ответ на сообщение** (как в WhatsApp): на ПК — правой кнопкой по сообщению → «Ответить», на телефоне —
  долгим нажатием. Нажатие на цитату — переход к исходному сообщению.
- **Поиск по переписке**: поле «Поиск» над списком чатов — по тексту, именам файлов, заданиям и именам
  коллег во всех чатах; нажатие на результат открывает чат на найденном сообщении.
- **Автообновление**: раз в несколько часов RafChat проверяет новую версию. Если есть — внизу списка чатов
  (на телефоне — сверху) появляется кнопка «Обновить до версии …». На ПК установщик сам закроет и
  снова запустит программу; на телефоне Android спросит «Обновить приложение?» (в первый раз попросит
  разрешить RafChat устанавливать обновления).

## Установка
Файлы лежат в **Releases → «rafchat-latest»**:
- `RafChat-Setup-<версия>.exe` — на каждый ПК. Нужны права администратора: установщик сам добавляет
  RafChat в исключения брандмауэра Windows, иначе коллеги не смогут присылать сообщения на этот ПК.
- `RafChat-<версия>.apk` — на телефоны Android. После установки разрешите уведомления. На Xiaomi в «Профиле»
  включите «Работа в фоне без ограничений» и «Автозапуск».

### Mac
`RafChat-<версия>-mac-x64.dmg` — для любого Mac (Intel и Apple M1…M4; на Apple M macOS при первом запуске
предложит установить Rosetta — согласитесь). Откройте .dmg и
перетащите RafChat в «Программы». Программа не подписана сертификатом Apple, поэтому при первом запуске:
правой кнопкой по RafChat → «Открыть» → «Открыть» (или «Системные настройки → Конфиденциальность и безопасность →
Всё равно открыть»). Разрешите доступ к локальной сети и входящие подключения, когда macOS спросит.

### iPhone
`RafChat-<версия>-iOS-unsigned.ipa` — для iPhone (iOS 16 и новее). Ставится без Mac, программой
**Sideloadly** на Windows: подключите iPhone кабелем, перетащите `.ipa` в Sideloadly, войдите своим Apple ID.
Затем на iPhone: Настройки → Основные → VPN и управление устройством → доверять своему Apple ID.
С бесплатным Apple ID подпись действует **7 дней** — потом снова «Start» в Sideloadly (переписка сохраняется).

Особенности iPhone:
- сообщения приходят, **пока RafChat открыт** (iOS усыпляет свёрнутые приложения, а сервера у нас нет);
  недоставленное ждёт у коллег и приходит сразу после открытия — ничего не теряется;
- при первом запуске iPhone спросит разрешение «Локальная сеть» — нажмите «Разрешить»;
- коллег iPhone находит сам, обходя адреса своей Wi-Fi сети (широковещание Apple без особого разрешения
  запрещает); полученные файлы — в «Файлы → На iPhone → RafChat».

**Подпись своим аккаунтом разработчика Apple (TestFlight, App Store).** Сборка подпишет приложение сама,
если в репозитории (Settings → Secrets and variables → Actions) есть секреты:
`IOS_CERT_P12_BASE64` и `IOS_CERT_PASSWORD` (сертификат Apple Distribution в .p12, base64),
`IOS_PROFILE_BASE64` (профиль для `ru.sharapov.rafchat`, base64), `IOS_TEAM_ID`,
по желанию `IOS_EXPORT_METHOD` (`app-store` по умолчанию или `ad-hoc`). Для автоматической отправки
в TestFlight добавьте ключ App Store Connect: `ASC_API_KEY_P8_BASE64`, `ASC_API_KEY_ID`, `ASC_ISSUER_ID`.

При первом запуске каждый вводит **имя**, **отдел** (по желанию) и **код организации**.
**Код организации должен быть одинаковым у всех**: придумайте его (например `Цех-2026`) и сообщите коллегам.
Устройства с другим кодом вашу переписку не видят и писать в неё не могут.

## Работа через интернет (из дома, в дороге) — свой сервер
В офисе всё идёт напрямую по локальной сети. Чтобы писать и получать сообщения, когда вы не в офисе,
нужен ретранслятор RafChat на вашем VPS (Ubuntu/Debian; можно рядом с VPN — порт отдельный, 47888).

**Автоматически, из программы на ПК** (заходить на VPS не нужно): ⚙ → «Установить сервер на VPS…» →
IP-адрес VPS, логин `root` и пароль → «Установить». RafChat сам подключится по SSH, поставит сервер как службу
(автозапуск), откроет порт, проверит связь и запомнит адрес. Пароль нигде не сохраняется.
**Адрес сервера расходится сам**: остальные ПК и телефоны организации подхватят его, как только окажутся
в одной сети с этим ПК (вписывать вручную не нужно).

Вручную — одной строкой в PowerShell на ПК (SSH встроен в Windows 10/11; попросит пароль VPS):

```
ssh root@АДРЕС_VPS "curl -fsSL https://raw.githubusercontent.com/sharapovrafail-bot/modelview/claude/adoring-edison-95p0fr/rafchat/server/install.sh | bash"
```

Если устройства не подключаются к серверу, откройте TCP-порт 47888 в панели хостинга.

**Мобильный интернет.** Операторы часто режут нестандартные порты (47888). Поэтому сервер слушает ещё и
свободные «веб-порты» (80, 443, 8080 — занятые VPN или другими службами пропускаются), а RafChat, если
основной порт не отвечает, сам перебирает запасные. Проверка с телефона: `http://АДРЕС_VPS/`.
Некоторые операторы (например, Билайн) пропускают подключение, но вырезают незашифрованный HTTP к
зарубежным серверам. Для них сервер открывает ещё и шифрованный порт (TLS: первый свободный из
2053/2083/2087/9443, сертификат создаётся сам), и RafChat переходит на него автоматически.

**Смена сервера** (например, перенос в Россию): поставьте новый сервер с любого ПК (⚙ → «Установить сервер на
VPS…») — новый адрес сам разойдётся по всем устройствам организации (через офисную сеть или через старый сервер):
у адреса есть время смены, и более новый заменяет старый.

**Адрес сервера встроен в установщики** (`rafchat/defaults.json`): RafChat на ПК и APK сразу знают сервер,
сотрудникам остаётся ввести только имя и код организации. Код организации в установщик не встраивается —
страница загрузки публичная.

- Кого нет в вашей сети, тот «в сети через интернет»; сообщения к нему идут через сервер:
  «✓ на сервере» — сервер принял, «✓✓» — получатель забрал.
- Выключенному получателю сервер хранит сообщения до 7 дней, файлы — до 3 дней.
- Файлы на сервере занимают не больше 3 ГБ, и на диске VPS всегда остаётся не меньше 1 ГБ свободного
  места (VPN и система не пострадают): при нехватке первыми удаляются самые старые файлы.
  Изменить: `RAFCHAT_MAX_STORE_GB` и `RAFCHAT_FILE_DAYS` в `/etc/systemd/system/rafchat-relay.service`.
- Файлы через сервер — до 50 МБ.
- **Сервер не может прочитать переписку**: всё шифруется на устройствах (AES-256-GCM) ключом из кода
  организации, а сам код на сервер не передаётся.
- Обслуживание: `systemctl status rafchat-relay`, журнал — `journalctl -u rafchat-relay`,
  обновление — та же команда установки.

## Если коллеги не появляются в списке
1. Проверьте, что все в одной сети (один роутер, один офис), а телефоны подключены к Wi-Fi этой же сети.
2. Проверьте, что на ПК RafChat поставлен установщиком: именно он создаёт правило брандмауэра «RafChat».
3. Если сеть разбита на сегменты (VLAN) и маяки до других ПК не доходят: ⚙ → «Профиль и сеть» →
   «Адреса других ПК» — впишите IP-адреса коллег через запятую.

Если маяки где-то теряются (энергосбережение Wi-Fi на телефоне, VPN на ПК), RafChat всё равно найдёт
собеседника: участник считается «в сети», как только от него пришло сообщение, а известные адреса
раз в несколько секунд опрашиваются напрямую по TCP («ты тут?»). Сообщения «Общего чата», отправленные,
когда кого-то ещё не было видно, досылаются ему, как только он появится (за последние сутки).

## Как устроено
| | |
|---|---|
| Поиск | каждые 4 с маяк «я здесь» (UDP 47800): широковещательно и на известные адреса; запасной путь — `GET /ping` по TCP |
| Сообщения и файлы | HTTP на TCP 47801: `POST /msg`, `GET /file?fid=` (с докачкой через Range) |
| Защита | все маяки и запросы подписаны HMAC-SHA256 ключом из кода организации; через сервер — ещё и шифрование AES-256-GCM |
| Сервер (необязательно) | `server/rafchat_relay.py` — «почтовый ящик» для зашифрованных сообщений, HTTP 47888 |
| Хранение | переписка — в SQLite на каждом устройстве; очередь недоставленного — у отправителя |

Файл из общего чата каждый получатель скачивает напрямую у отправителя. Поэтому, пока файл не скачан,
отправитель должен хотя бы раз появиться в сети. Текст сообщений не шифруется, только подписывается —
для локальной сети организации этого обычно достаточно.

## Разработка
- ПК: `pip install -r pc/requirements.txt`, затем `python pc/rafchat_pc.py`.
  Чтобы запустить две копии на одном ПК, задайте каждой свои переменные `RAFCHAT_HOME`, `RAFCHAT_PORT`
  и `RAFCHAT_UDP`, а в «Адресах других ПК» укажите адрес второй копии (например `127.0.0.1:47900`).
- iPhone: проект в `ios/` (SwiftUI). На Mac: `brew install xcodegen`, `xcodegen generate` в папке `ios/`,
  затем открыть `RafChat.xcodeproj` в Xcode.
- Android: проект в `android/` — открыть в Android Studio или собрать `gradle assembleRelease`.
  APK подписывается тем же постоянным ключом, что и RafLink (`raflink/android/app/raflink.keystore`).
