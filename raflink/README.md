# RafLink — телефон Android ↔ ПК по Wi-Fi

Автор: Рафаил Шарапов · связь: rafail@sharapov-cnc.ru

Окно телефона на компьютере: папки и фото телефона видны на ПК, файл **перетаскивается мышкой**
в Проводник или на рабочий стол. Обратно — бросьте файл с ПК на окно RafLink (или на мини-капсулу),
он попадёт в «Загрузки/RafLink» на телефоне. С телефона — «Поделиться → На ПК (RafLink)» из любого
приложения, кнопки «Отправить файлы» и «Фото на ПК»; файлы приходят в папку «Входящие»
(по умолчанию `Загрузки\RafLink`). Интернет и облако не нужны — только общая сеть Wi-Fi.

Проверено под Windows 11 и Android 14 (Xiaomi 11T Pro, HyperOS).

## Где взять
Вкладка **Releases → «raflink-latest»** на GitHub (собирается автоматически):
- `RafLink-<версия>.apk` — на телефон;
- `RafLink-Setup-<версия>.exe` — установщик для ПК (права администратора не нужны).

## Установка на телефон (Xiaomi)
1. Скачайте APK на телефон и откройте. Разрешите установку из этого источника («Неизвестные источники»).
   Если HyperOS предлагает «проверить приложение» — можно пропустить: оно ставится не из Google Play.
2. Откройте RafLink и пройдите блок **«Настройка телефона»** — все четыре пункта должны стать зелёными:
   - **Доступ ко всем файлам** — чтобы ПК видел папки телефона;
   - **Уведомления** — значок связи в шторке;
   - **Работа в фоне без ограничений** — иначе Xiaomi усыпит связь через несколько минут;
   - **Автозапуск (Xiaomi)** — включите переключатель у RafLink.
3. Дополнительно на Xiaomi: в списке недавних приложений потяните карточку RafLink вниз и нажмите
   замок — система не будет её закрывать.

## Установка на ПК
1. Запустите `RafLink-Setup-<версия>.exe`. Windows SmartScreen может предупредить
   («Неизвестный издатель») — «Подробнее → Выполнить в любом случае». Установщик сам закроет
   запущенную старую версию; ярлык RafLink появится в «Пуске». Обновление — так же, поверх.
2. Выберите телефон в списке «Телефоны в сети» (или введите его адрес — он виден на экране RafLink)
   и введите 6-значный код с экрана телефона. Подключение запоминается.

Папки и альбомы подписаны так же, как на телефоне («Загрузки», «Камера», «Скриншоты»);
вкладка **«Галерея»** показывает альбомы из приложения «Галерея». Назад — стрелка ← у пути,
боковая кнопка мыши, Alt+← или Backspace.

### Новое в 0.4
- **Экран телефона на ПК** — вкладка «Экран» → «Показать экран», на телефоне нажать уведомление RafLink → «Начать»
  (Android требует подтверждения на каждый показ). Мышь: щелчок — нажатие, протянуть — свайп, удержать — долгое
  нажатие, колесо — прокрутка, правая кнопка или Esc — «Назад»; печатать можно прямо с клавиатуры ПК; внизу кнопки
  «Назад», «Домой», «Недавние», «Шторка», «Скриншот», «Блокировка».
  **Управление мышкой** включается один раз: RafLink на телефоне → «Управление с ПК (мышью)» → «Специальные
  возможности» → «Скачанные приложения» → «RafLink — управление с ПК» → включить. Если переключатель серый
  (Xiaomi, Android 13+): Настройки → Приложения → RafLink → ⋮ → «Разрешить ограниченные настройки».
- **Буфер обмена**: ПК → телефон — значок буфера в шапке (можно включить «отправлять автоматически»);
  телефон → ПК — кнопка «Буфер на ПК» или «Поделиться» текстом → «На ПК (RafLink)». Автоматически с телефона нельзя:
  Android запрещает фоновым приложениям читать буфер.
- **Докачка**: если Wi-Fi пропал, передача ждёт до ~3 минут и продолжает с того же места, а не с начала.
- **Шифрование**: связь идёт по TLS (порт 47703); ключ хранится в защищённом хранилище телефона, ПК запоминает
  отпечаток сертификата и не примет подменённый телефон. В шапке — «Подключено · 🔒». Уже подключённый ПК
  переходит на шифрование сам, повторно вводить код не нужно.

**С телефона на ПК** файлы встают в очередь на телефоне, а программа на ПК забирает их за пару секунд
(во «Входящие»). Брандмауэр Windows этому не мешает; если ПК выключен — файлы уйдут, когда он включится.

**VPN на ПК** (Angel VPN и др.): RafLink ищет телефон в сети только при подключении и при потере
связи, и только через обычные адаптеры (не через VPN). Если VPN всё же мешает связи с телефоном —
включите в нём «Разрешить локальную сеть» (LAN / split tunneling) или добавьте RafLink в исключения.

Закрытие окна убирает RafLink к часам — файлы с телефона по-прежнему принимаются.
В «Настройках» — папка «Входящие», тема, запуск вместе с Windows.

## Как устроено
| Часть | Где | Что делает |
|---|---|---|
| `android/` | Kotlin, Android 8+ | фоновая служба, HTTP-сервер на порту **47700**, объявление в сети `_raflink._tcp` (mDNS) |
| `pc/raflink_pc.py` | Python + PySide6 | окно, поиск телефона, перетаскивание, забор файлов из очереди телефона |
| `design/ios/` | | макеты в стиле iOS — по ним сделано оформление с версии 0.3 |
| `design/RafLink-prototype.html` | | первый прототип (тёмная тема, версии 0.1–0.2) |

Безопасность: ПК получает ключ доступа только после ввода кода с экрана телефона; без ключа телефон
ничего не показывает. С версии 0.4 всё идёт по шифрованному каналу (TLS).

Перетаскивание из окна: файл сначала скачивается во временную папку, затем отдаётся Проводнику.
Большие файлы удобнее сохранять кнопкой **«На ПК»** или правой кнопкой → «Сохранить в папку…».

## Разработка
- ПК: `pip install -r pc/requirements.txt`, затем `python pc/raflink_pc.py`.
- Без телефона: `python pc/tools/mock_phone.py <папка>` — имитатор телефона (код 123456),
  подключайтесь к адресу `127.0.0.1`.
- Android: открыть `android/` в Android Studio или `gradle assembleRelease` (нужен Android SDK).
  APK подписывается постоянным ключом `android/app/raflink.keystore`, поэтому новые версии
  ставятся поверх старых.
