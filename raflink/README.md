# RafLink — телефон Android ↔ ПК по Wi-Fi

Окно телефона на компьютере: папки и фото телефона видны на ПК, файл **перетаскивается мышкой**
в Проводник или на рабочий стол. Обратно — бросьте файл с ПК на окно RafLink (или на мини-капсулу),
он попадёт в «Загрузки/RafLink» на телефоне. С телефона — «Поделиться → На ПК (RafLink)» из любого
приложения, кнопки «Отправить файлы» и «Фото на ПК»; файлы приходят в папку «Входящие»
(по умолчанию `Загрузки\RafLink`). Интернет и облако не нужны — только общая сеть Wi-Fi.

Проверено под Windows 11 и Android 14 (Xiaomi 11T Pro, HyperOS).

## Где взять
Вкладка **Releases → «raflink-latest»** на GitHub (собирается автоматически):
- `RafLink-<версия>.apk` — на телефон;
- `RafLink.exe` — на ПК (установка не нужна, просто запустить).

## Установка на телефон (Xiaomi)
1. Скачайте APK на телефон и откройте. Разрешите установку из этого источника («Неизвестные источники»).
   Если HyperOS предлагает «проверить приложение» — можно пропустить: оно ставится не из Google Play.
2. Откройте RafLink и пройдите блок **«Настройка телефона»** — все четыре пункта должны стать зелёными:
   - **Доступ ко всем файлам** — чтобы ПК видел папки телефона;
   - **Уведомления** — значок связи в шторке;
   - **Работа в фоне без ограничений** — иначе Xiaomi усыпит связь через несколько минут;
   - **Автозапуск (Xiaomi)** — включите переключатель у RafLink.
3. Дополнительно на Xiaomi: в списке недавних приложений потяните карточку RafLink вниз и нажмите
   замок — система не будет её закрывать.

## Установка на ПК
1. Запустите `RafLink.exe`. Windows SmartScreen может предупредить («Неизвестный издатель») —
   «Подробнее → Выполнить в любом случае».
2. Брандмауэр спросит доступ к сети — разрешите для **частных сетей**. Сеть Wi-Fi в Windows
   должна быть «Частной» (Параметры → Сеть и Интернет → Wi-Fi → свойства сети).
3. Выберите телефон в списке «Телефоны в сети» (или введите его адрес — он виден на экране RafLink)
   и введите 6-значный код с экрана телефона. Подключение запоминается.

Закрытие окна убирает RafLink к часам — файлы с телефона по-прежнему принимаются.
В «Настройках» — папка «Входящие», тема, запуск вместе с Windows.

## Как устроено
| Часть | Где | Что делает |
|---|---|---|
| `android/` | Kotlin, Android 8+ | фоновая служба, HTTP-сервер на порту **47700**, объявление в сети `_raflink._tcp` (mDNS) |
| `pc/raflink_pc.py` | Python + PySide6 | окно, поиск телефона, перетаскивание, приём файлов на порту **47701** |
| `design/RafLink-prototype.html` | | прототип интерфейса, по которому сделано оформление |

Безопасность: ПК получает ключ доступа только после ввода кода с экрана телефона; без ключа телефон
ничего не показывает. Данные идут по локальной сети без шифрования (HTTPS — в планах).

Перетаскивание из окна: файл сначала скачивается во временную папку, затем отдаётся Проводнику.
Большие файлы удобнее сохранять кнопкой **«На ПК»** или правой кнопкой → «Сохранить в папку…».

## Разработка
- ПК: `pip install -r pc/requirements.txt`, затем `python pc/raflink_pc.py`.
- Без телефона: `python pc/tools/mock_phone.py <папка>` — имитатор телефона (код 123456),
  подключайтесь к адресу `127.0.0.1`.
- Android: открыть `android/` в Android Studio или `gradle assembleRelease` (нужен Android SDK).
  APK подписывается постоянным ключом `android/app/raflink.keystore`, поэтому новые версии
  ставятся поверх старых.
